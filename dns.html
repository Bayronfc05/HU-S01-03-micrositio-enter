¿Cómo se traduce un nombre a una IP?

DNS (Sistema de Nombres de Dominio) es el mecanismo que traduce nombres como google.com a una dirección IP, que es lo que realmente identifica a un servidor en internet. Cuando escribes una URL, tu computador le pregunta a un servidor DNS "¿cuál es la IP de este nombre?", y recibe una respuesta como 172.217.162.142. Es como buscar el número de teléfono de un contacto en tu agenda antes de poder llamarlo: tú recuerdas nombres, pero el sistema necesita el número real para conectar la llamada.
