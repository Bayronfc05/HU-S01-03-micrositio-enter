# Ejercicio E1 — Reto de terminal (sin mouse)

**Grabación:** https://drive.google.com/drive/u/0/folders/1Ir1sLdPmkHUIFgZteFiBxu7TzR3n7_LB

## Qué hice

Creé un árbol de 3 niveles de carpetas con 8 archivos, sin usar el explorador
de archivos ni el mouse, usando solo comandos de terminal (Git Bash).

### Comandos usados

```bash
mkdir -p reto/nivel1/
cd reto
touch a.txt b.txt
cd nivel1
touch c.txt d.txt
mkdir nivel2
cd nivel2
ls -la #para listar

# renombrar
mv nombre-viejo.txt nombre-nuevo.txt

# borrar 
rm ...
rm -rf
```

## Resultado

- Árbol de 3 niveles creado con 8 archivos 
- 2 archivos renombrados 
- 4 archivos borrados (mitad del total) 
- Carpeta borrada 

## Qué aprendí
- Manejo de comandos para la navegación y creación, eliminación y modificación de directorios, comandos para listar y tambien para ver mis rutas actuales, fue un ejerccio muy comodo dado que la practicidad y visibilidad de los comandos ejecutados ayuda a la memorización y aclaración de la funcionalidad de los mismos.
